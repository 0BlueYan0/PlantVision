Place the plant image classifier here as `PlantClassifier.mlpackage`, `PlantClassifier.mlmodel`, or `PlantClassifier.mlmodelc`.

The wither (枯萎) classifier goes here as `WitherClassifier.mlpackage` / `.mlmodel` / `.mlmodelc`.

> `WitherClassifier.mlmodel` currently checked in is a **placeholder**: a naive colour
> baseline (green = healthy, brown/yellow = withered) generated by
> `dataset_tools/make_test_wither_model.swift`. It lets the whole Mac→relay→visionOS
> pipeline run end to end before the real model exists. Replace it with the model trained
> by `dataset_tools/train_wither_classifier.swift` on real Lantana tiles (Stage B).
